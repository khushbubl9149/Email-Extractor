# Email-Extractor
To write python code to extract email from text using Regular Expression.
### Week 3: Regex and Text Processing – Email Extractor

**Project Title:** Email Extractor Using Python Regular Expressions

**Objective:** To develop a Python program that extracts email addresses from a text file using regular expressions.

**Description:** In this project, I used Python's `re` module to identify and extract email addresses from text. I implemented the `re.findall()` function to find all matching email patterns and used the `set()` function to remove duplicate email addresses. The extracted email addresses were displayed on the screen and saved into a separate output file.

**Key Concepts Learned:**
- Introduction to Regular Expressions (Regex).
- Pattern matching in Python.
- Use of `re.findall()`.
- Extracting email addresses from text.
- Removing duplicate values using sets.
- Reading and writing text files.

**Outcome:** Successfully developed an email extraction tool using Python Regex and improved my understanding of text processing and pattern matching.
